# PFP Bot

A Discord bot built with Python for managing and supporting the PFP Discord community.

## Features

- Discord server management
- Member management
- Moderation commands
- Permission management
- Database-backed member information
- Roster management
- Welcome messages
- Custom bot commands
- Organized command modules using Cogs
